# 业务流程图设计文档：基于 AI Agent 的多轮对话系统

## 1. 概述

本文档旨在梳理“基于 AI Agent 的多轮对话系统”的主要业务流程。系统覆盖用户身份鉴权、文档管理与 RAG 索引构建、基于 LangGraph 的异步流式 Agent 问答，以及运维监控日志记录四大核心子流程。

文档采用标准 Mermaid 流程图进行展示，方便开发团队快速理解各模块之间的业务依赖与数据流转。

## 2. 系统全景业务流程图

```mermaid
flowchart TD
    Start([用户访问 Web 界面]) --> LoadPage[渲染登录页/加载验证码]
    LoadPage --> InputAuth[输入用户名、密码与验证码]
    InputAuth --> AuthCheck{身份校验}
    
    AuthCheck -- 失败 --> AuthFail[提示错误并刷新验证码] --> InputAuth
    AuthCheck -- 成功 --> GetToken[返回 JWT Token 并进入主界面]
    
    GetToken --> Choice{用户操作选择}
    
    %% 分支一：文件上传
    Choice -- 上传文档 --> UploadFile[选择 .md / .word 文件]
    UploadFile --> ParseDoc[LlamaIndex 解析文档与切片]
    ParseDoc --> SaveVector[向量化并写入 Chroma 数据库]
    SaveVector --> UpdateDocMeta[写入 PostgreSQL 文档元数据]
    UpdateDocMeta --> UploadFinish[前端提示上传成功]
    UploadFinish --> Choice
    
    %% 分支二：多轮对话
    Choice -- 发起对话 --> SendMsg[发送用户问题]
    SendMsg --> LangGraphStart[触发 LangGraph 状态机]
    LangGraphStart --> LLMDecide{Agent 决策: 是否需要检索?}
    
    LLMDecide -- 是 --> CallTool[调用 ems_handbook_tool]
    CallTool --> QueryChroma[查询 Chroma 向量库]
    QueryChroma --> ReturnContext[注入 RETRIEVED_CONTEXT 槽位]
    ReturnContext --> LLMGenerate
    
    LLMDecide -- 否 --> LLMGenerate[LLM 生成回答]
    
    LLMGenerate --> StreamSSE[FastAPI 异步 SSE 流式输出]
    StreamSSE --> FrontendRender[前端打字机渲染呈现]
    FrontendRender --> LogTrace[异步上报 Langfuse 与写入日志]
    LogTrace --> Choice

```

## 3. 核心子业务流程图

### 3.1 身份认证与图形验证码流程

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户
    participant FE as 前端界面
    participant GW as Nginx 反向代理
    participant API as FastAPI 鉴权模块
    participant DB as PostgreSQL 数据库

    User->>FE: 打开系统登录页
    FE->>GW: GET /api/v1/auth/captcha
    GW->>API: 转发请求
    API->>API: 生成 captcha_id 与验证码图片
    API->>DB: 写入 captcha_records 表
    API-->>FE: 返回 captcha_id 与 Base64 图片
    FE-->>User: 渲染图形验证码

    User->>FE: 输入账号、密码与验证码点击登录
    FE->>GW: POST /api/v1/auth/login
    GW->>API: 转发登录请求
    API->>DB: 查询验证码记录并校验
    alt 验证码无效或过期
        API-->>FE: 返回 1001 错误
        FE-->>User: 提示验证码错误，刷新验证码
    else 验证码通过
        API->>DB: 查询 users 表校验密码哈希
        alt 密码错误
            API-->>FE: 返回 1002 错误
            FE-->>User: 提示用户名或密码错误
        else 认证成功
            API->>DB: 标记验证码已使用
            API-->>FE: 返回 JWT Token
            FE-->>User: 跳转至主控制台界面
        end
    end

```

## 3.2 文档上传与 RAG 索引构建流程

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户
    participant FE as 左侧侧边栏 (上传区)
    participant API as FastAPI 文件网关
    participant RAG as LlamaIndex 引擎
    participant Chroma as Chroma 向量数据库
    participant DB as PostgreSQL 数据库

    User->>FE: 选择本地文档 (.md / .docx) 并点击上传
    FE->>API: POST /api/v1/documents/upload (Multipart)
    API->>API: 校验文件扩展名与文件大小
    alt 格式不支持
        API-->>FE: 返回 2001 错误 (格式不符)
    else 格式校验通过
        API->>DB: 写入 documents 表 (状态: indexing)
        API->>RAG: 异步触发文档解析与向量化
        RAG->>RAG: 文档读取、文本清洗与 Chunk 切分
        RAG->>RAG: 调用 Embedding 模型生成向量
        RAG->>Chroma: 写入向量数据与 Metadata
        Chroma-->>RAG: 持久化成功确认
        RAG->>DB: 更新 documents 表 (状态: ready)
        API-->>FE: 返回上传与索引成功响应
        FE-->>User: 刷新左侧已加载文档列表
    end

```

## 3.3 异步流式多轮对话与 Tool 执行流程

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户
    participant FE as 右侧对话框
    participant API as FastAPI 消息服务
    participant LG as LangGraph Agent
    participant Tool as ems_handbook_tool
    participant Chroma as Chroma 数据库
    participant LLM as LLM 大模型API
    participant LF as Langfuse 监控

    User->>FE: 输入问题并发送
    FE->>API: POST /api/v1/chat/stream (SSE 长连接)
    API->>LF: 创建 Trace 记录
    API->>LG: 压入用户 Message，启动 Agent 工作流

    LG->>LLM: 发送历史上下文与 Prompt 思考下一步
    LLM-->>LG: 返回决策结果 (需要调用工具)

    opt 触发 RAG 工具调用
        LG->>API: 推送 SSE 事件: event: tool_start
        API-->>FE: 界面显示 "正在检索知识库..."
        LG->>Tool: 执行 ems_handbook_tool(query)
        Tool->>Chroma: 相似度向量检索
        Chroma-->>Tool: 返回相关文本 Chunk List
        Tool-->>LG: 返回格式化后的上下文
        LG->>API: 推送 SSE 事件: event: tool_end
    end

    LG->>LLM: 结合 RETRIEVED_CONTEXT 再次请求生成答案
    loop 异步流式生成
        LLM-->>LG: 返回文本 Token 切片
        LG->>API: 压入 SSE 流
        API-->>FE: 推送 event: token 数据
        FE-->>User: 打字机实时渲染显示
    end

    LG->>API: 流程结束 (event: done)
    API->>LF: 异步上报 Token 消耗与执行轨迹
    API->>API: 将完整对话消息持久化至 chat_messages 表

```

## 4. 业务角色与系统交互矩阵 (泳道图说明)

| 业务环节 | 客户端/用户 (Frontend) | 接入网关 (Nginx) | 后端服务 (FastAPI / LangGraph) | 数据与监控 (Chroma / DB / Langfuse) |
| --- | --- | --- | --- | --- |
| **鉴权准备** | 请求图形验证码 | SSL 加密解密与反向代理 | 生成图形验证码并暂存 | 将验证码及过期时间存入 `captcha_records` 表 |
| **登录校验** | 提交用户名、密码、验证码 | 转发 HTTP POST 请求 | 校验验证码，比对数据库密码哈希 | 查验 `users` 表，校验成功后发放 Token |
| **知识库维护** | 上传 `.md` / `.word` 文件 | 转发文件流 | 调用 LlamaIndex 切分并生成向量 | 向量存入 Chroma，元数据存入 `documents` 表 |
| **Agent 对话** | 发起流式对话，实时接收 SSE | 维持长连接 (关闭 Buffer) | 运行 LangGraph 状态机，决策并调用 Tool | 检索向量知识库，记录日志与 Langfuse Trace |
