# 需求分析文档：基于 AI Agent 的多轮对话系统

## 1. 项目概述

本项目旨在构建一个基于 API KEY 的 AI Agent 多轮对话系统，核心技术栈深度融合 LangGraph、LlamaIndex、Chroma 与 Langfuse。系统采用前后端分离架构，前端由 FastAPI 承载并提供定制化的 HTML 页面，保障设计感与交互体验；后端负责处理异步流式对话及检索增强生成（RAG）逻辑。系统底层支持通过 Docker Compose 进行容器化部署。

## 2. 核心架构与技术栈

* **前端展示**：基于 FastAPI 挂载的静态 HTML 页面。
* **后端服务**：FastAPI + LangGraph 框架。
* **大语言模型通信**：基于异步（Async）与流式（Streaming）技术。
* **RAG 引擎**：LlamaIndex。
* **向量数据库**：Chroma。
* **监控与调试**：Langfuse。
* **关系型数据库**：PostgreSQL。
* **反向代理与安全**：Nginx（HTTPS，手工生成证书）。

## 3. 功能需求详细说明

### 3.1 身份认证模块

| 需求项 | 详细描述 |
| --- | --- |
| 登录机制 | 采用用户名与密码结合的身份验证方式。 |
| 验证码防护 | 登录页必须集成图形验证码功能，验证码需确保清晰可见，防止自动化破解。 |

### 3.2 前端界面与交互设计

| 需求项 | 详细描述 |
| --- | --- |
| 页面标识 | Web 界面需显著展示字样："上海佳得森辉新材料(集团)有限公司RAG 问答 Demo（作者：吴常春）"。 |
| 布局规范 | 采用左右分栏布局。左侧为文档管理区，右侧为多轮对话核心区。 |
| 文件上传功能 | 左侧区域需提供"上传文件"按钮，支持 `.md` 和 `.word` 格式文档的上传。 |
| UI 视觉体验 | 界面需经过专业 UI 设计，保障视觉上的美观大方与流畅度。 |

### 3.3 核心对话与 Agent 模块

* **多轮对话机制**：登录成功后，用户在右侧界面与大模型进行交互。前后端数据传输必须采用异步、流式（Server-Sent Events 或 WebSocket）输出，确保打字机呈现效果。
* **Agent 路由控制**：后端工作流必须使用 LangGraph 构建，负责多轮对话的状态管理与决策。
* **Tool 封装与集成**：将 LlamaIndex 的检索功能标准封装为名为 `ems_handbook_tool` 的工具。LangGraph 在多轮对话中根据用户意图自主调用该工具。

### 3.4 知识库与 RAG 构建

* **测试数据加载**：项目根目录设有一个 `document` 文件夹，专门用于存放初始测试文档。
* **索引构建**：使用 LlamaIndex 读取 `document` 文件夹内的文件，解析并构建向量索引。
* **持久化存储**：向量化后的数据需持久化存储至 Chroma 向量数据库中，直接供检索工具使用。

## 4. 非功能性需求

### 4.1 部署与容器化

| 组件 | 部署要求 |
| --- | --- |
| 容器编排 | 编写 `docker-compose.yml` 文件，实现一键拉起部署。 |
| 依赖服务 | 配置文件需包含 Langfuse 服务及其底层依赖的数据库，以及项目业务所需的 PostgreSQL 数据库。 |
| 反向代理 | 使用 Nginx 构建 HTTPS 反向代理，SSL 证书采用手工创建与配置的方式。 |

### 4.2 开发规范与环境

* **代码规范**：所有前后端代码、脚本与配置文件必须配备详尽的中文注解。
* **运行环境**：项目需完美适配名为 `test` 的本地 Conda 虚拟开发环境。
* **环境变量**：系统运行依赖的配置需提取，在项目运行完成后或交付时必须生成标准的 `.env.example` 模板文件。
* **日志系统**：后端需集成完善的日志记录功能，详细记录系统运行状态与错误堆栈，方便后台排查问题。
