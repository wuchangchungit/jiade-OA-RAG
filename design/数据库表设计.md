# 数据库表设计文档

## 1. 概述与设计原则

本文档描述“基于 AI Agent 的多轮对话系统”的数据存储层设计，包含关系型数据库（PostgreSQL）的结构设计以及向量数据库（Chroma）的集合定义。

### 1.1 存储策略分工

* **PostgreSQL (关系型数据库)**：负责存储结构化数据，包括用户身份凭证、验证码记录、会话状态、对话历史明细、上传文档元数据以及系统排查日志。
* **Chroma (向量数据库)**：负责存储文档切片（Chunks）的文本向量表示及其上下文元数据，供 `ems_handbook_tool` 进行语义检索。

### 1.2 命名规范

* 表名与字段名均采用下划线命名法（`snake_case`）。
* 主键统一采用 `id` 或具象化的 ID 字段（如 `session_id`）。
* 时间类型统一采用标准时间戳 `TIMESTAMP WITH TIME ZONE`，采用 UTC 时间存储。

## 3. PostgreSQL 关系型数据库设计

### 3.1 用户表 (`users`)

存储系统的注册用户与管理员身份信息。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `id` | `BIGSERIAL` | PRIMARY KEY | - | 用户自增主键 |
| `username` | `VARCHAR(50)` | UNIQUE, NOT NULL | - | 用户名 |
| `password_hash` | `VARCHAR(255)` | NOT NULL | - | 加密后的密码哈希 |
| `status` | `SMALLINT` | NOT NULL | `1` | 账号状态 (1: 正常, 0: 禁用) |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 账号创建时间 |
| `updated_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 信息更新时间 |

---

### 3.2 验证码记录表 (`captcha_records`)

用于登录环节的图形验证码校验与过期清理。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `captcha_id` | `VARCHAR(64)` | PRIMARY KEY | - | 验证码唯一标识 UUID |
| `code` | `VARCHAR(10)` | NOT NULL | - | 验证码正确字符 (忽略大小写) |
| `is_used` | `BOOLEAN` | NOT NULL | `FALSE` | 是否已被消费使用 |
| `expires_at` | `TIMESTAMPTZ` | NOT NULL | - | 验证码到期时间 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 验证码生成时间 |

---

### 3.3 对话会话表 (`chat_sessions`)

记录用户开启的多轮对话会话。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `session_id` | `VARCHAR(64)` | PRIMARY KEY | - | 会话唯一标识 UUID |
| `user_id` | `BIGINT` | FOREIGN KEY | - | 关联的用户 ID (`users.id`) |
| `title` | `VARCHAR(255)` | NOT NULL | `'新对话'` | 会话标题 (自动生成或取首句) |
| `is_deleted` | `BOOLEAN` | NOT NULL | `FALSE` | 软删除标识 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 会话创建时间 |
| `updated_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 最后交互时间 |

---

### 3.4 对话消息明细表 (`chat_messages`)

存储会话内部的具体消息内容，包含 LangGraph 状态与 Langfuse 追踪信息。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `id` | `BIGSERIAL` | PRIMARY KEY | - | 消息主键 |
| `session_id` | `VARCHAR(64)` | FOREIGN KEY, NOT NULL | - | 所属会话 ID (`chat_sessions.session_id`) |
| `role` | `VARCHAR(20)` | NOT NULL | - | 角色: `user`, `assistant`, `system`, `tool` |
| `content` | `TEXT` | NOT NULL | - | 消息主体内容 |
| `tool_calls` | `JSONB` | NULL | - | 工具调用详情 (记录 LangGraph 工具参数与输出) |
| `langfuse_trace_id` | `VARCHAR(128)` | NULL | - | 关联的 Langfuse 追踪 Trace ID |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 消息发送时间 |

---

### 3.5 文档元数据表 (`documents`)

记录根目录 `document` 及用户前端动态上传的文档状态。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `document_id` | `VARCHAR(64)` | PRIMARY KEY | - | 文档唯一标识 UUID |
| `file_name` | `VARCHAR(255)` | NOT NULL | - | 原始文件名 |
| `file_path` | `VARCHAR(512)` | NOT NULL | - | 服务器磁盘绝对/相对路径 |
| `file_size` | `BIGINT` | NOT NULL | - | 文件大小 (字节 Byte) |
| `file_type` | `VARCHAR(20)` | NOT NULL | - | 文件类型 (`md`, `doc`, `docx`) |
| `status` | `VARCHAR(30)` | NOT NULL | `'indexing'` | 状态: `indexing`, `ready`, `failed` |
| `uploader_id` | `BIGINT` | NULL | - | 上传者 ID，系统内置文档可为空 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 文件上传/导入时间 |

---

### 3.6 系统日志表 (`system_logs`)

记录后台关键节点运行状态与异常信息，方便运维排查问题。

| 字段名 | 数据类型 | 约束 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| `id` | `BIGSERIAL` | PRIMARY KEY | - | 日志自增主键 |
| `log_level` | `VARCHAR(10)` | NOT NULL | - | 日志级别 (`INFO`, `WARN`, `ERROR`) |
| `module_name` | `VARCHAR(50)` | NOT NULL | - | 触发模块 (如 `Auth`, `LangGraph`, `RAG`) |
| `message` | `TEXT` | NOT NULL | - | 日志摘要消息 |
| `stack_trace` | `TEXT` | NULL | - | 异常堆栈详细信息 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | `CURRENT_TIMESTAMP` | 日志记录时间 |

## 5. PostgreSQL DDL 建表 SQL 脚本

以下为可直接在 PostgreSQL 数据库中执行的 DDL 建表脚本，包含索引建设计划。

```sql
-- 1. 创建用户表
CREATE TABLE IF NOT EXISTS users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    status SMALLINT NOT NULL DEFAULT 1,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 2. 创建验证码记录表
CREATE TABLE IF NOT EXISTS captcha_records (
    captcha_id VARCHAR(64) PRIMARY KEY,
    code VARCHAR(10) NOT NULL,
    is_used BOOLEAN NOT NULL DEFAULT FALSE,
    expires_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 3. 创建对话会话表
CREATE TABLE IF NOT EXISTS chat_sessions (
    session_id VARCHAR(64) PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL DEFAULT '新对话',
    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 4. 创建对话消息明细表
CREATE TABLE IF NOT EXISTS chat_messages (
    id BIGSERIAL PRIMARY KEY,
    session_id VARCHAR(64) NOT NULL REFERENCES chat_sessions(session_id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL,
    content TEXT NOT NULL,
    tool_calls JSONB DEFAULT NULL,
    langfuse_trace_id VARCHAR(128) DEFAULT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 5. 创建文档元数据表
CREATE TABLE IF NOT EXISTS documents (
    document_id VARCHAR(64) PRIMARY KEY,
    file_name VARCHAR(255) NOT NULL,
    file_path VARCHAR(512) NOT NULL,
    file_size BIGINT NOT NULL,
    file_type VARCHAR(20) NOT NULL,
    status VARCHAR(30) NOT NULL DEFAULT 'indexing',
    uploader_id BIGINT REFERENCES users(id) ON DELETE SET NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 6. 创建系统日志表
CREATE TABLE IF NOT EXISTS system_logs (
    id BIGSERIAL PRIMARY KEY,
    log_level VARCHAR(10) NOT NULL,
    module_name VARCHAR(50) NOT NULL,
    message TEXT NOT NULL,
    stack_trace TEXT DEFAULT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- ---------------------------------------------------------
-- 创建高频查询索引
-- ---------------------------------------------------------

-- 对话会话表：按用户ID与更新时间查询
CREATE INDEX IF NOT EXISTS idx_chat_sessions_user ON chat_sessions(user_id, updated_at DESC);

-- 对话消息明细表：按会话ID与创建时间排序查询
CREATE INDEX IF NOT EXISTS idx_chat_messages_session ON chat_messages(session_id, created_at ASC);

-- 验证码表：按到期时间清理过期验证码
CREATE INDEX IF NOT EXISTS idx_captcha_expires ON captcha_records(expires_at);

-- 系统日志表：按日志级别与时间过滤
CREATE INDEX IF NOT EXISTS idx_system_logs_level_time ON system_logs(log_level, created_at DESC);

```
